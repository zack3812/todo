# TO-DO Panel v1.3.3 发布说明

**发布日期**：2026-09-16

## 本次更新

### 修复：macOS 输入法候选框不可见
- 创建待办等输入场景看不到输入法候选词：展开态窗口置顶级别从 screen-saver 降为 floating，输入法候选词可正常浮出。
- 折叠态保持 screen-saver 级别，折叠条在 macOS 菜单栏拦截带内仍可点击展开。

## 自动升级说明（Windows）
- 应用启动约 8 秒后自动检查新版本，之后每 6 小时检查一次；也可在设置页手动「检查更新」。
- 国内网络会自动使用镜像源下载，进度条显示下载状态；完成后点击「重启安装」自动完成升级。
