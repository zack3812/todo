# TO-DO Panel v1.4.0 发布说明

**发布日期**：2026-09-17

## 本次更新

### 待办删除更安全
- 普通删除进入垃圾篓，可随时恢复。
- 只有永久删除或清空垃圾篓才会同步删除云端副本。
- 云端删除失败会自动排队，重新连接后继续同步。

### 修复数据串联问题
- 修复重复待办 ID 导致修改或删除一条时影响其他待办的问题。
- 启动时自动修复历史重复 ID，同时保留分类、截止时间和云端身份。
- 修复随笔记无法新建，以及云端变更重复回传等问题。

### 安全与维护
- 云同步令牌改由系统安全存储加密，旧数据自动迁移。
- 便携工作区不再携带设备凭据和同步配置。
- 统一待办同步数据转换与删除重试逻辑，全量同步会如实显示失败数量。
